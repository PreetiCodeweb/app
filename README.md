# 🎬 Netflix Clone (SwiftUI)

A modern Netflix-inspired streaming application built entirely with **SwiftUI**. This project recreates the core user experience of Netflix, including a cinematic home screen, hero banners, movie categories, search functionality, personalized watchlists, detailed content pages, and a responsive mobile-first interface.

## 🚀 Overview

This project was developed to explore advanced SwiftUI concepts while replicating the design and user experience of a real-world streaming platform. The application focuses on clean architecture, responsive layouts, state management, and modern iOS development practices.
